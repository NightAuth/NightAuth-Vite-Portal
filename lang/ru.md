# NightAuth Custom Customer Portal (Vite) — Поставьте нам звезду на GitHub ⭐

Официальный шаблон клиентского портала для [NightAuth](https://nightauth.org). Разработан на базе **Vite** и **TailwindCSS**, полностью воспроизводит функционал и интерфейс встроенного портала клиентов NightAuth (единый визуальный стиль, полный жизненный цикл авторизации и лицензирования, а также нативная локализация на 10 языков) через API `/api/customer/*`.

Официальный портал: [https://nightauth.org](https://nightauth.org)

## Включенные страницы и сценарии

| Страница | Описание | Используемые эндпоинты |
| :--- | :--- | :--- |
| `/signin` | Вход по логину/паролю или лицензионному ключу | `auth/signin` |
| `/signup` | Активация лицензии и регистрация аккаунта | `auth/signup` |
| `/2fa-required` | Двухфакторная аутентификация (TOTP или резервные коды) | `auth/2fa-verify` |
| `/forgot-password` · `/reset-password?token=` | Полный цикл восстановления пароля | `auth/forgot-password`, `auth/reset-password` |
| `/` | Панель клиента: сводка, сброс HWID, загрузки, сессии и 2FA | `data`, `actions/*`, `account`, `account/2fa/*` |

## Возможности

- 🎨 **Оригинальный дизайн NightAuth**: Глубокий темный фон `#060608`, динамическая интерактивная сетка, стеклянные карточки и автоматическая акцентная подсветка из `/api/customer/info`.
- 🌐 **Встроенная поддержка 10 языков**: Английский, испанский, немецкий, французский, итальянский, польский, португальский, русский, турецкий и китайский с интерактивным выбором флага.
- 📱 **Динамическая адаптация**: Автоматически учитывает статус приложения (закрытая регистрация, отключение сброса паролей, режим обслуживания).
- ⚡ **Клиент без фреймворков**: Чистый статический HTML и модульный ES JavaScript для мгновенной загрузки.
- 🔒 **Сквозное шифрование учетных данных (libsodium Sealed Boxes)**: Пароли, коды 2FA и ключи запечатываются открытым ключом сервера (`crypto_box_seal`) прямо в браузере перед отправкой.
- 🛡️ **Встроенная капча Cap**: Proof-of-work капча с локальной проверкой через WebAssembly (WASM) без сторонних трекеров.
- 🐳 **Поддержка Docker и Docker Compose**: Многоэтапная сборка контейнера с запуском от непривилегированного пользователя.

## Установка и запуск

1. **Клонировать репозиторий**:
   ```bash
   git clone https://github.com/NightAuth/NightAuth-Vite-Portal.git
   cd NightAuth-Vite-Portal
   ```

2. **Установить зависимости с помощью pnpm**:
   ```bash
   pnpm install
   ```

3. **Настроить переменные окружения**:
   ```bash
   cp .env.example .env
   ```
   Настройте `.env`:
   ```env
   PUBLIC_NIGHTAUTH_API_URL=https://nightauth.org
   PUBLIC_NIGHTAUTH_PORTAL_ID=ваш_portal_id
   PUBLIC_NIGHTAUTH_APP_NAME="Мое Приложение"
   ```
